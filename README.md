## Назначение решения
Проблема: сложность выбора будущей профессии. Школьникам сложно самостоятельно оценить свои интересы и связать их с конкретными профессиями.

Идея: создание чат-бота, который поможет школьникам 9-11 классов найти свою профессию. Симулятор превращает сложные и долгие профориентационные тесты в увлекательную историю в формате визуальной новеллы с интеграцией AI. Пользователь может создать своего героя, пройти 2 истории и задать вопросы Советчику - AI-наставнику по профориентации.


## Основной пользовательский сценарий

1. Пользователь запускает чат-бот по ссылке.
2. После нажатия кнопки “начать” автоматически запускается игра.
3. Пользователь создаёт своего персонажа путём выбора пола, цвета волос и кожи. Герой отображается в историях и главном меню.
4. Отображается главное меню, в котором пользователь, взаимодействуя с кнопками, получает возможность выбрать прохождение историй или задать вопрос Советчику.  
5. При выборе прохождения историй можно выбрать одну из двух историй. При прохождении в определенные моменты доступны выборы, которые влияют на результат - возможный вариант профессии.
6. При выборе Советчика пользователь текстом пишет вопрос, получает короткий ответ и возвращается в главное меню.


## Состав и архитектура решения

Код запускается единым контейнером и разделен на модули, которые отвечают за разные элементы бота:
1. создание героя;
2. главное меню и истории;
3. советчик и работа с AI;
4. работа с базой данных;
5. клавиатуры и отправка картинок.

Данные пользователя (его ID), созданного персонажа и выборов хранятся в SQLite. Картинки хранятся в папке image. Также используются MAX Bot API и OpenAI-совместимый AI-провайдер.


## Запуск одной командой
Перед запуском нужно склонировать репозиторий на свой ПК и создать файл .env, заполнив переменные (хранятся на 1 слайде презентации).

Команда для запуска с отдельным созданием файла env: docker compose up --build -d

Команда для запуска с автоматическим созданием файла env:
Linux, macOS, Git Bash:

```bash
printf "BOT_TOKEN=your_bot_token\nAI_API_KEY=your_api_key\nAI_BASE_URL=https://api.example.com/v1\nAI_MODEL=your_model\n" > .env; docker compose up -d --build
```

Windows PowerShell:

```powershell
@("BOT_TOKEN=your_bot_token","AI_API_KEY=your_api_key","AI_BASE_URL=https://api.example.com/v1","AI_MODEL=your_model") | Set-Content .env -Encoding ascii; docker compose up -d --build
```


## Необходимые параметры окружения

Для запуска требуются:
1. установленные Docker и Git;
2. доступ к интернету;
3. токен для чат-бота и ключ доступа к OpenAI-совместимому API.

Перед запуском рекомендуется создать файл .env по примеру .env.example.


## Переменные окружения

1. BOT_TOKEN - токен бота MAX;
2. AI_API_KEY - ключ AI-провайдера;
3. AI_BASE_URL - базовый URL AI-провайдера;
4. AI_MODEL - название модели;
5. DATABASE_PATH="./data/bot.sqlite" - путь к файлу SQLite.


## Используемые порты

Порты не используются.


## Зависимости

Среда выполнения: Node.js 24 и Yarn.

Основные пакеты:
1. @maxhub/max-bot-api — клиент MAX Bot API;
2. openai — клиент для OpenAI-совместимых API;
3. dotenv — чтение .env при локальном запуске;
4. встроенный node:sqlite — работа с базой без нативных модулей.

Инструменты разработки: typescript, tsx, nodemon, eslint, prettier. Точные версии зафиксированы в файле зависимостей.

## Внешние сервисы и интеграции

1. MAX Bot API — работа с мессенджером MAX: приём сообщений и нажатий кнопок, отправка ответов и загрузка изображений.
2. AI-провайдер с OpenAI-совместимым адресом  — генерация ответов Советчика. Адрес, ключ и модель задаются переменными окружения.


## Описание работы с данными

Данные хранятся в SQLite-файле. База и таблицы создаются автоматически при первом запуске, миграции применяются автоматически. Имеются следующие таблицы:

1. players - ID пользователя, выбранные настройки персонажа, путь к его картинке;
2. user_sessions - выборы пользователя;
3. schema_migrations - применённые миграции.

Персональные данные в БД не хранятся.


## Порядок работы с тестовыми данными

Готовых данных нет. Для проверки содержимого БД:

```bash
docker compose exec bot node --input-type=module -e "import {DatabaseSync} from 'node:sqlite'; const d=new DatabaseSync('/app/data/bot.sqlite'); console.log(d.prepare('SELECT user_id, gender, hair_color, skin_tone FROM players').all())"
```


## Пошаговый сценарий проверки

1. Соберите и запустите контейнер: docker compose up --build -d.
2. Проверьте логи: docker compose logs bot. Ошибок быть не должно. Предупреждения допустимы.
3. Откройте бота в MAX и нажмите «Начать». Придёт приветствие с кнопкой «Поехали!».
4. Нажмите «Поехали!», выберите пол, цвет волос и цвет кожи. Бот присылает картинки вариантов на каждом шаге.
5. После выбора кожи придёт сообщение «Вау, получился отличный герой!...» с кнопками «Истории» и «Советчик» и картинкой героя.
6. Нажмите «Истории» → «1». Придёт пролог истории «Тайна чёрного города» с картинкой и кнопкой «Узнать, что будет дальше!». Пройдите историю.
7. После прохождения нажмите «Советчик», отправьте вопрос, например: «Я не знаю, кем хочу быть». Придёт сообщение «Нужно немного подождать...», затем короткий ответ, затем главное меню.
8. Проверьте запрещённую тему, например: «Как взломать сайт?». Бот должен вежливо отказать и сменить тему диалога.


## Примеры ожидаемого поведения системы

1. Нажатие стартовой кнопки «Начать» - получаем приветствие и кнопку «Поехали!».
2. Выбор пола персонажа - получаем сообщение «Теперь выберем цвет волос», три картинки, три кнопки: светлые/тёмные/рыжие.
3. Выбор цвета кожи - видим главное меню с картинкой героя.
4. Вопрос Советчику по теме профессий - короткий ответ, без звёздочек, по теме.
5. Вопрос Советчику на запрещенную тему - вежливый отказ и смена темы.
6. Спорный вопрос Советчику (например, про трудоустройство в 14 лет без согласия родителей)	- получаем ответ в стиле: «Это спорная ситуация. Обсуди со взрослым».
7. Сообщение Советчику без смысла - рассказ от Советчика, что он делает.
8. Выбор кнопки историй - предложение выбрать одну из двух историй.
9. Запуск истории - получаем стартовое сообщение и картинку с созданным героем. По ходу истории есть 4-5 картинок, выбор вариантов ответа, форматирование текста.


## Известные ограничения

1. Для работы Советчика требуется сторонний AI-провайдер.
2. База данных хранится локально.
3. Советчик обрабатывает только 1 вопрос, нет диалога.
4. Картинки загружаются в MAX при первом обращении после запуска бота, поэтому первый показ может быть медленнее.


## Остановка и повторный запуск

- Остановка контейнера без удаления контейнера и данных: docker compose stop
- Остановка контейнера без удаления данных: docker compose down
- Остановка контейнера с полным удалением данных: docker compose down -v
- Запуск остановленного контейнера: docker compose start
- Запуск остановленного контейнера после down: docker compose up -d
- Пересборка и запуск после изменения кода: docker compose up --build -d
